Network Security Glossary

Use this sheet to keep the vocabulary straight while learning TLS, certificates, and auth flows.

Core Terms

TLS
Transport security for a connection: confidentiality, integrity, and server authentication.
HTTPS
HTTP carried over TLS.
mTLS
Mutual TLS: both client and server present certificates.
Certificate
A signed document that binds an identity to a public key.
Private key
The secret used to prove ownership of the public key in the certificate.
Public key
The shareable half of a key pair that others use to verify signatures or encrypt to you.
CSR
Certificate Signing Request: a signed request for a CA to issue a certificate.
CA
Certificate Authority: an entity you trust to sign certificates.
Trust store
The collection of trusted root certificates your OS or runtime uses for chain validation.
OAuth 2.0
An authorization framework for scoped access to APIs.
JWT
A compact token format that carries claims; not the same thing as OAuth 2.0.
Kerberos
A ticket-based network authentication protocol commonly used in enterprise realms.
