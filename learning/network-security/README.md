# Teach Practice

Use this file as a scratchpad when trying the teach skill.

## Topic

What are we learning?

## What I Already Know

Write the rough version first, even if it is incomplete.

## Teach Back

Have the agent explain the concept in simple language, then a little more precisely.

## Check Understanding

- What still feels fuzzy?
- What examples would make this click?
- What should I be able to do next?

## Follow-up

Record any actionable next steps or things to revisit later.
