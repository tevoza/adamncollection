# Copilot Customization Resources

## Knowledge

- [GitHub Docs: GitHub Copilot Cookbook](https://docs.github.com/en/copilot/tutorials/copilot-cookbook)
  A good map of Copilot prompting, response customization, context, and tools.
- [GitHub Docs: Customization library](https://docs.github.com/en/copilot/tutorials/customization-library)
  Curated examples of custom instructions, prompt files, and custom agents.
- [GitHub Docs: Your first custom instructions](https://docs.github.com/en/copilot/tutorials/customization-library/custom-instructions/your-first-custom-instructions)
  Shows the basic shape of personal custom instructions.
- [GitHub Docs: Adding personal custom instructions](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/add-custom-instructions/add-personal-instructions)
  Explains personal instruction scope and priority.
- [GitHub Docs: Adding repository custom instructions](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/add-custom-instructions/add-repository-instructions)
  Explains repository-wide and path-specific instructions, plus limits and precedence.
- [GitHub Docs: Your first prompt file](https://docs.github.com/en/copilot/tutorials/customization-library/prompt-files/your-first-prompt-file)
  Shows how to package a reusable task prompt instead of retyping long asks.
- [ArXiv: Analyzing Prompt Influence on Automated Method Generation: An Empirical Study with Copilot](https://arxiv.org/abs/2402.08430)
  Useful for understanding which prompt features improve output quality.
- [ArXiv: Repository-Level Prompt Generation for Large Language Models of Code](https://arxiv.org/abs/2206.12839)
  Good background on why repository context matters when prompting code models.
